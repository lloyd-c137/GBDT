## 问题 2：可能筛选规律（三层证据）

### 1. 原始标注统计

ACM 状态与二元评级交叉表：

```text
label_binary           0  1
acm_status                 
bronze                 0  4
honorable_mention      0  4
no_award_record        3  0
not_participated       2  2
participated_no_award  3  0
silver                 0  2
```

岗位与原始评级分布：

```text
label_grade  A  B  C
target_role         
前端开发工程师      1  1  1
后端开发工程师      0  2  0
客户端开发工程师     0  0  2
数据工程师        3  1  1
测试开发工程师      0  1  3
算法工程师        0  1  0
运维开发工程师      0  2  1
```

GitHub 链接提供情况与评级：

```text
label_grade  A  B  C
github_url          
提供链接         4  3  1
未提供链接        0  5  7
```

技能、学校、GitHub 与文本字段仅作描述和解析质量检查，不进入模型；简历模板化且 B 样本仅 20 份；描述性关联不能证明因果，也无法从这些字段推断稳定的筛选条件。工作年限统计：正类均值 5.75 年，C 级均值 7.12 年。

### 2. 模型实际规则

正式 GBDT 的树分裂和特征重要性会记录在 `feature_analysis.md`；分数是未校准模型输出。由于样本数小、树数量和深度固定，特征重要性只反映该拟合模型中的分裂贡献，不能解释为因果。

### 3. 消融与简单树对照

E2 相比 E1 的 balanced accuracy 差值为 **+0.000**；两者 LOOCV 错例同为 14、20，说明 GBDT 没有优于 ACM 单特征浅树，也没有在这轮验证中显示工作年限带来的额外预测提升。移除 ACM 的 E3 比 E2 低 **0.125** balanced accuracy，支持 ACM 是这组实验中的主要区分信息。结果仅限小样本探索。

## 稳定性与覆盖范围

20 个 leave-one-training-sample-out 扰动模型输出见 `stability_analysis.csv`。`stability_positive_count` 表示 20 次中的正类计数，不是正确概率；阈值分类翻转 0 份，扰动分数标准差均值 0.0253。超出工作年限范围或训练中 ACM×年限组合覆盖的简历 148 份，建议人工复核。全模型分数共形成 4 个并列分数档位，结果表保留原始同分，不强制排序。

## 限制与错误案例

- 标签仅来自 B 企业历史评级；LOOCV 有反复试验造成的选择偏差。
- 样本量极小，类别与特征覆盖稀疏，P 数据来源分布可能不同。
- ACM 与工作年限只是少量结构字段；文本、岗位适配、学校等均未进入模型。未使用的学校、年龄、薪资不构成扣分依据。
- 模型分数不是录用概率；预测不能用于自动筛选或淘汰。
- E2 错例编号：14;20。
